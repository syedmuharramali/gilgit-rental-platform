# Gilgit Rental Platform

A production-grade MERN stack rental platform designed for Gilgit, Pakistan.

The platform connects renters with verified property owners for hostels, rooms, apartments, and houses while supporting the complete rental lifecycle from property discovery to digital rental agreements.

## Core Features

- Email and Google authentication
- Role-based authentication and authorization
- Owner identity verification
- Property verification
- Property listings and advanced search
- Smart property matching
- Gilgit Living Score
- Favorites and saved searches
- Rental applications
- Property viewing scheduling
- Real-time messaging
- Digital rental agreements
- Electronic signatures
- Tenancy management
- Move-in and move-out inspections
- Maintenance requests
- Reviews and ratings
- Notifications
- Admin dashboard
- Audit logs
